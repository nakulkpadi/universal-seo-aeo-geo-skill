# Structured Data
Recommend schema only when supported by visible page facts. Common mappings: Product for products,
Article/BlogPosting for editorial, LocalBusiness for eligible local entities, Event for events,
JobPosting for jobs, Course for courses, RealEstateListing-like appropriate vocabulary only when
valid, SoftwareApplication for software where applicable, BreadcrumbList for breadcrumbs.
Never fabricate reviews, aggregateRating, author credentials, prices, availability or dates.
