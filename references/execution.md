# Controlled Execution
Safe low-risk staging candidates: title, meta description, H1, OG/Twitter text, lang, viewport.
Always backup, create a diff, re-audit, and show validation. Review-only: canonical, robots/noindex,
redirects, hreflang, URL changes, schema factual claims, large body rewrites, internal-link
restructuring. Never deploy automatically. Recommended lifecycle:
Detected -> Proposed -> Staging Applied -> Validated -> Approved -> Externally Deployed -> Production Verified.
