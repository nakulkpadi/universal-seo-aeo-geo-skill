# SEO
Check status/indexability, title, meta description, H1 hierarchy, canonical, robots directives,
language, viewport, internal links, image alt text, descriptive anchors, content depth, duplicate
signals, Open Graph, Twitter metadata, structured data, sitemap/robots discoverability, and page
purpose. Site mode additionally reviews crawl depth, orphan-like discovery gaps, repeated metadata
and page-family/index-bloat patterns. Avoid arbitrary length dogma; flag clearly missing, empty,
duplicated or extreme metadata and explain context.
