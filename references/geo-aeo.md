# GEO / AEO / Citation Quality
Evaluate answer-first structure, question headings, concise definitions, factual specificity,
quantified claims, attribution, primary-source evidence, author/reviewer identity, dates,
methodology, original data, extractable passages, FAQ usefulness, entity clarity and schema.
Flag unsupported superlatives, excessive hedging and claims without visible evidence. `llms.txt`
is an optional discoverability aid, not a ranking guarantee. AI visibility should be measured
with explicit benchmark exports when available, not invented.
